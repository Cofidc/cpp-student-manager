1.项目简介：本项目是基于c++的学生管理系统，保存和查看学生的学号、姓名、成绩
2.已有功能：基础的增删改查，以及输入检测
3.编译与运行：在包含 student.cpp、main.cpp、student.h 的项目目录中执行命令
    g++ -std=c++17 -Wall -Wextra student.cpp main.cpp -o student.exe
    .\student.exe        
4.使用限制：数据仅保存在内存中，退出后丢失
5.测试记录：
| 测试操作 | 预期结果 | 实际结果 |
| --- | --- | --- |
| 显示学生信息 | 正确显示已有学生 | 通过 |
| 添加重复学号 | 拒绝添加，原数据不变 | 通过 |
| 将成绩修改为 `101` | 拒绝修改，原成绩不变 | 通过 |
| 输入 `abc`，再输入合法选项 | 提示格式错误，之后仍能正常操作 | 通过 |
| 用空字符串调用改名函数 | 返回 `false`，学生信息不变 | 通过 |
