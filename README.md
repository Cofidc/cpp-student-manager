# C++ 学生管理系统

一个命令行学生管理系统，用于管理学生的学号、姓名和成绩。项目用于练习 C++ 类与封装、构造函数、组合、引用、`vector`、输入检查和多文件组织。

## 学习进度

- 第一周：使用结构体实现学生信息的增删改查，练习引用、容器、输入检查和多文件组织。
- 第二周：将学生数据封装为 `Student` 类，通过构造函数检查初始数据，并用 `StudentManager` 统一管理学生集合和增删改查操作。
- 第二周独立练习：观察构造、析构、拷贝构造、拷贝赋值和参数传递；通过示例学习浅拷贝、深拷贝、继承、虚函数、抽象类和虚析构函数。这些示例不属于主项目功能。
- 下一阶段：第三周学习常用容器、算法、智能指针和 RAII，结合实际需要改进项目。

## 已有功能

- 添加学生，检查学号为正数、姓名非空、成绩合法和学号不重复。
- 显示所有学生，或按学号查找学生。
- 修改学生姓名和成绩。
- 按学号删除学生。
- 检查成绩范围（0～100），并处理输入格式错误。

## 代码组织

| 文件或类 | 职责 |
| --- | --- |
| `student.h` | 声明 `Student`、`StudentManager` 和单个学生的显示函数；定义学生的成员访问与校验方法 |
| `student.cpp` | 实现管理器的查重、添加、显示、查找、修改和删除，以及单个学生的显示函数 |
| `main.cpp` | 菜单交互、输入格式检查、调用管理器、捕获添加时的参数异常和显示操作结果 |

- `Student` 的数据为私有成员，getter 使用 `const`，setter 校验失败时返回 `false` 并保留原值。
- 三参数构造函数使用初始化列表，参数非法时抛出 `std::invalid_argument`，不创建无效学生对象。
- `StudentManager` 通过私有的 `vector<Student>` 保存学生，使用组合管理集合；查重由管理器负责。
- 学生以值的形式保存，使用编译器生成的拷贝和析构行为；修改外部学生对象不会影响已加入管理器的副本。

## 编译与运行

开发环境：Windows、G++，使用 C++17 标准。

在包含 `student.cpp`、`main.cpp`、`student.h` 的项目目录中打开终端，执行：

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic student.cpp main.cpp -o student.exe
```

编译成功后运行：

```powershell
.\student.exe
```

按照菜单提示输入选项，输入 `0` 退出程序。

修改源码后需要重新编译。如果终端无法识别 `g++`，可使用已安装编译器的完整路径执行编译命令。

## 使用限制

- 数据仅保存在内存中，退出后丢失，尚未实现文件保存与读取。
- 当前通过 `cin >> name` 读取姓名，不支持姓名中包含空格。
