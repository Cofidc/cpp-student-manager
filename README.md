# C++ 学生管理系统

一个命令行学生管理系统，用于管理学生的学号、姓名和成绩。项目用于练习 C++ 结构体、引用、`vector`、输入检查和多文件组织。

## 已有功能

- 添加学生，并检查学号是否重复。
- 显示所有学生，或按学号查找学生。
- 修改学生姓名和成绩。
- 按学号删除学生。
- 检查成绩范围（0～100），并处理输入格式错误。

## 编译与运行

开发环境：Windows、G++，使用 C++17 标准。

在包含 `student.cpp`、`main.cpp`、`student.h` 的项目目录中打开终端，执行：

```powershell
g++ -std=c++17 -Wall -Wextra student.cpp main.cpp -o student.exe
```

编译成功后运行：

```powershell
.\student.exe
```

按照菜单提示输入选项，输入 `0` 退出程序。

## 使用限制

- 数据仅保存在内存中，退出后丢失，尚未实现文件保存与读取。
- 当前通过 `cin >> name` 读取姓名，不支持姓名中包含空格。
